# Tiny Rituals

A bilingual iOS ritual tracker for mothers and young children.

## About the project

Tiny Rituals helps mothers track small daily rituals for themselves and their children without pressure or guilt. The app is free and built with the goal of being genuinely useful.

## Current features

- SwiftUI interface with a soft pastel design
- Ritual cards with one-tap daily completion
- Streak counter and total completed days
- 100-day calendar history for every ritual
- Custom ritual creation with your own icon and color
- Swipe to delete a ritual
- Data is saved on the device between launches
- English and Russian interface, following the phone language

## Technologies

- Swift
- SwiftUI
- Xcode
- iOS
- `UserDefaults` and `Codable` for local persistence
- String Catalog for localization

## Run locally

1. Clone the repository: `git clone https://github.com/AlexandraPlat/tiny-rituals-ios.git`
2. Open `TinyRituals.xcodeproj` in Xcode
3. Choose an iPhone simulator and press Run (Cmd + R)
