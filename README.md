
# Tiny Rituals

A bilingual iOS ritual tracker for mothers and young children.

## About the project

Tiny Rituals helps mothers track small daily rituals for themselves and their children without pressure or guilt.

## Current features

- SwiftUI interface
- Habit and ritual cards
- Daily completion tracking
- Streak counter
- Calendar history
- Custom ritual creation
- Soft pastel design

## Technologies

- Swift
- SwiftUI
- Xcode
- iOS

## Project status

MVP in progress.

## Planned features

- Russian and English localization
- Local data persistence
- Notifications
- Child profiles
- Improved calendar history
